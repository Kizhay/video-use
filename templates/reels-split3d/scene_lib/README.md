# Готовые анимированные вставки (проверены рендером)

Копируй нужную в `<проект>/scenes/` вместе с `_k.js`, подставляй свои тексты/числа, прописывай в `project.json → scenes`
(start/end подряд без дыр, пустые промежутки — `empty.js`). Проверка: `node render.mjs --project P --out P/stills --stills t1,t2`.
Чтобы запустить в Linux: `PUPPETEER_EXECUTABLE_PATH=/opt/pw-browsers/chromium`.

| файл | что показывает | длительность | слой |
|---|---|---|---|
| counter.js | счётчик «0 → 1 000 000+» с подчёркиванием | 4.4 с | split (верх 1080×960) |
| funnel.js | воронка показы → клики → заказы → выкупы | 4 с | split |
| gauge.js | спидометр ДРР, стрелка уезжает в красное | 3 с | split |
| calc.js | калькулятор прибыли строка за строкой | 3.9 с | split |
| morph_ui.js | одна фигура превращается: кнопка → загрузка → галочка → карточка → переключатель → график → уведомление → кнопка | 12 с | `"layout":"full"` |

Правила: числа только настоящие автора, иначе на кадре подпись «ПРИМЕР · УСЛОВНЫЕ ЧИСЛА» (она уже в сценах); один акцент цвета (`ACC` в `_k.js`),
красный только для угрозы; ничего случайного (только от времени сцены); не размещай графику ниже y≈820 в split — там субтитры.
Идея morph_ui — из галереи prompt-motion.com «Shape morphing through UI states» (@twoclipping); код написан заново, чужие промпты и видео не копируем.
Ролик-пример собран так: `talkhead.py --clean` → `render.mjs` → `layer.py --layout split`.
