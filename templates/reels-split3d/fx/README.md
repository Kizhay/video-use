# fx — эффекты на человеке и картинки из интернета

Проверено 11.10.2026 на тестовом ролике с настоящим человеком (4 ядра, 16 ГБ, без GPU):
вырезание человека 48–59 кадров/с (RVM mobilenetv3 ONNX), наложение эффектов 8–11 кадров/с в 1080x1920.

| файл | что делает |
|---|---|
| person_mask.py | маска человека по кадрам (Robust Video Matting, рекуррентная — край не дрожит) |
| effects.py | фон, текст за человеком, светящийся контур, вырезная обводка, голова в круге, прилипшие стикеры |
| fetch_assets.py | иконки и логотипы (Iconify, simple-icons, значок сайта), фото (Openverse; Pexels/Unsplash/Pixabay при ключах), assets.json с лицензиями |
| shot.mjs | скриншот страницы сайта (Ozon и Wildberries блокируют облачный адрес: 403 и 498) |

Инструкция для монтажёра — раздел 1.6 в MONTAGE.md.
