# ТЗ: моушн-графика верхней половины Reels (версии 2–4)

Ролик 1080×1920, 30 fps, 62 с. Верх 1080×960 — графика (делаешь ты), низ — говорящая голова.
Субтитры на шве, в верхней половине занимают полосу y≈840..960 → ничего важного ниже y=800.
Первые 3.2 с по центру экрана висит крупный заголовок (его рисует движок) — в сцене s01 в эти секунды
держи графику спокойной и не в центре по вертикали (лучше y 120..600).

## Движок
Шаблон: /Users/aleksej/Developer/video-use/templates/reels-split3d/ — прочитай lib/engine.js и lib/kit.js.
Сцена — ES-модуль: `export default function setup(ctx) { ... return { tl, update(lt,p,t){} } }`
ctx = { gsap, THREE, kit, scene, camera, ui, fx, W:1080, H:960, dur, start, words, params }.
- **Основной инструмент — GSAP** (уже подключён: `ctx.gsap`; плагины импортируй сам:
  `import { DrawSVGPlugin } from 'gsap/DrawSVGPlugin.js'; ctx.gsap.registerPlugin(DrawSVGPlugin)` — так же SplitText, MorphSVGPlugin, CustomEase).
  Создай `const tl = gsap.timeline({ paused: true })`, наполни его в setup и верни `{ tl }` — движок сам делает
  `tl.seek(lt)` на каждом кадре. lt = секунды от начала сцены.
- Графика — HTML/CSS/SVG внутри `ui` (div 1080×960, position:absolute). Свой CSS добавляй через <style> в ui.
  Three.js (scene/camera) — только если 3D реально украшает; по умолчанию не используй.
- Фон рисует движок (тема задана в project.json). Свой фон не рисуй, если в ТЗ версии не сказано иначе.
- Слова с таймкодами: words.json проекта (глобальное время). Время события в сцене = word.s − start сцены.
  Ищи слово только начиная со start своей сцены. Анимацию «ключевого» появления запускай на 0.1–0.15 с РАНЬШЕ слова.
- Шрифт: 'MB' (Montserrat 900/800/500, кириллица) — уже подключён.

## Принципы «дорогого» моушена (обязательно)
1. Длительности: вход элемента 300–500 мс, мелочь 200–300 мс. Выход 200–300 мс.
2. Easing по роли: вход `power3.out`/`expo.out`, выход `power2.in`, перемещение `power2.inOut`. Overshoot (`back.out(1.4)`) — только на 1 акцентном элементе сцены.
3. Stagger 50–80 мс для групп (строки, иконки, буквы).
4. Follow-through: тень/подложка доезжают на 60–100 мс позже главного.
5. Палитра версии строго по ТЗ версии: 1 фон, 1 акцент, 1–2 нейтральных, красный только для «угрозы».
6. Один якорь на сцену, крупное первым. Поля 64–96 px. Много воздуха, никакой каши.
7. Переход между сценами ОДИН тип на весь ролик (указан в ТЗ версии): последние 0.3 с сцены — выход, первые 0.4 с — вход. Сцены не должны начинаться с пустого кадра дольше 0.15 с.
8. Пауза: после ключевого момента 300–500 мс покоя (лёгкое «дыхание» — scale 1→1.02, медленный дрейф, допустимо).
9. Кадр никогда полностью не замирает, кроме финала s12.
10. Тексты в графике короткие (≤3 слова), по-русски, не повторяют субтитры дословно: цифры, ярлыки, статусы. «OZON» латиницей. Никаких эмодзи — иконки рисуй SVG (линейные, stroke 6–8px, round caps).
