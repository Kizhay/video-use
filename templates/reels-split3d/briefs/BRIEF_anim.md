## Движок (уже готов — НЕ трогай его файлы)
Шаблон: /Users/aleksej/Developer/video-use/templates/reels-split3d/ — прочитай lib/engine.js, lib/kit.js, lib/subs.js.
Официальные правила GSAP: ~/.claude/skills/gsap-timeline/SKILL.md, gsap-core/SKILL.md, gsap-plugins/SKILL.md.
Сцена — ES-модуль `export default function setup(ctx) { ...; return { tl, update(lt,p,t){} } }`,
ctx = { gsap, THREE, kit, ui, fx, W, H, dur, start, words, params }. Делай `const tl = ctx.gsap.timeline({paused:true})`,
наполняй и возвращай { tl } — движок сам делает tl.seek(lt) на каждом кадре. lt — секунды от начала сцены.
Графика — HTML/CSS/SVG в ctx.ui (абсолютное позиционирование, px). Плагины GSAP: `import { DrawSVGPlugin } from 'gsap/DrawSVGPlugin.js'`
(также MotionPathPlugin, MorphSVGPlugin, SplitText, CustomEase) и ctx.gsap.registerPlugin(...).
Шрифты в проекте: 'Jost' (субтитры), 'Title' (заголовок), 'MB' (Montserrat 500/800/900). Можно свои — положи TTF в папку проекта
и добавь в project.json "fonts".

## Твоя папка проекта (указана в задании) — ты её владелец
- project.json — fps, duration, слова, заголовок первых 3.4 с (рисует движок), субтитры-маркер (рисует движок).
  Ты заполняешь ТОЛЬКО массив "scenes" (и для doodle — "subs.hideRanges"). Сцены должны покрывать весь ролик подряд
  от 0 до duration без дыр (start следующей = end предыдущей; последняя end ≥ duration). Пустые промежутки — сцена,
  которая ничего не рисует. У каждой сцены "transition":"none".
- words.json — слова ГОТОВОГО смонтированного ролика с таймкодами (секунды выходного видео). Прочитай целиком
  python'ом и разбей текст на смысловые биты с таймкодами. Анимацию ключевого события начинай на 0.1–0.15 с РАНЬШЕ слова.
- scenes/*.js — твои сцены; общий код — scenes/_ui.js.

## Принципы (обязательно)
- Длительности: вход 300–500 мс (power3.out/expo.out), выход 200–300 мс (power2.in), stagger 50–80 мс, overshoot back.out только на 1 акцент.
- Один якорь на кадр, много воздуха, 1 акцент цвета, красный только для угрозы. Тексты в графике ≤3 слов, по-русски,
  не дублируют речь дословно (цифры, ярлыки, статусы). «OZON» латиницей. Никаких эмодзи — иконки рисуй SVG.
- Детерминизм: кадры рендерятся вразнобой в 4 потока — никакого состояния между кадрами, Math.random/Date запрещены (kit.rng(seed)).
- Ритм: картинка меняется каждые 2–4 с, кадр не стоит.
- ЗВУКОВ НЕТ (это только картинка).
