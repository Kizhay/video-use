# Задача: монтажный лист (EDL) говорящей головы

Видео — вертикальный Reels, автор читает один и тот же текст с многими дублями. Нужен чистый ролик:
- Если фраза повторяется 2+ раз — это неудачные дубли. Берём ПОСЛЕДНИЙ УДАЧНЫЙ (целиком произнесённый, без запинки и обрыва). Если последний оборван — предпоследний целый.
- Выкидываем: фальстарты, оборванные фразы («Также он потерял...»), оговорки, реплики «в сторону» (например «Как много слов китайцы?» — это шутка себе под нос, вырезать), мусор распознавания.
- Паузы: внутри фразы паузу >0.35 с вырезаем (режем range на два). Между фразами оставляем ~0.15–0.25 с воздуха. Темп живой, без провисаний.
- Порядок фраз — по смыслу сценария (обычно хронологический: последний удачный дубль каждого смыслового куска по очереди).
- Резы ТОЛЬКО по границам слов. Подушки: начало = word.start − 0.06, конец = word.end + 0.10 (не залезая на соседнее слово; если соседнее слово ближе — середина промежутка).
- Ничего не придумывай: если смысловой кусок не произнесён ни разу целиком — бери лучшее и отметь в reason.

## Входы
- Пословная расшифровка (Whisper, бывают ошибки распознавания): transcripts/<ИМЯ>.json, поле words: [{text,start,end}] (элементы с пустым text — паузы).
- Сводка по фразам: takes_packed.md.
Прочитай JSON своего видео через python (печатай слова с таймкодами кусками), не гадай по сводке.

## Выход
Запиши /Users/aleksej/Desktop/Видео-монтаж/img112x/edit/edl_<ИМЯ>.json:
{
 "source": "<ИМЯ>",
 "ranges": [{"start": 1.00, "end": 4.21, "quote": "точный текст куска", "reason": "почему этот дубль"}],
 "fix": {"Азон": "Ozon", "Азоне": "Ozon", "селером": "селлерам", "сплажкой": "с плашкой", "...": "..."},
 "fix_at": [{"t": 33.12, "w": "правильное слово"}],
 "total_s": 61.2
}
- fix — глобальная замена ошибок распознавания для субтитров (ключ = слово как в JSON без знаков препинания, значение = правильное написание; маркетплейс пишем «Ozon»). fix_at — точечная замена слова, начинающегося в момент t (если глобальная замена не подходит). Значение может быть «» (убрать слово-паразит из субтитров) или из нескольких слов.
- Проверь: ranges идут по возрастанию времени внутри источника и не пересекаются; суммарная длина посчитана; прочитай склеенные quote подряд — должно читаться как связный чистый текст без повторов.
Не задавай вопросов. В ответе: итоговый склеенный текст ролика, длительность, 3–5 спорных решений.
