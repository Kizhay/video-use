# Каталог идей для анимированных вставок (что показать на экране под слова)

Источник вдохновения — галерея prompt-motion.com (моушн-ролики, сделанные Claude, и разборы 230+ реальных промптов). Берём ИДЕИ и приёмы,
не материал: видео и промпты там принадлежат авторам — не копируй чужие работы, тексты промптов и анимации, не скачивай видео. Пересказано и
адаптировано под вертикальные Reels для продавцов маркетплейсов. Свежие идеи можно посмотреть самому (`curl -sL https://prompt-motion.com/blog/<статья>`,
статьи: ai-motion-graphics-prompts, make-ai-motion-graphics-look-less-ai, ai-launch-video-prompts, ai-explainer-video-prompts, remotion-vs-hyperframes),
если в задании есть время; не затягивай разведку больше 3–4 минут.

## 0. Главное правило: у каждой вставки есть причина
Не «набор эффектов», а одна мысль на вставку: что зритель должен понять. Перед написанием сцен выпиши по `words.json` для каждой мысли ролика:
`время слова → что показываем (тип из каталога ниже) → откуда движение (что из чего вырастает)`. Если не можешь сказать, зачем вставка, — убери её.
Ритм (`BRIEF_rhythm.md`) обязателен: событие каждые 2–4 с, но не ради количества.

## 1. Типы вставок (категории галереи → что это в наших Reels)
| Тип | Что показываем | Когда брать | Как собрать у нас |
|---|---|---|---|
| Кинетическая типографика (самая частая, ~100 работ) | слово-удар, слова собираются по буквам, цифра-счётчик, подчёркивание/зачёркивание, смена слова с разным временем ухода и прихода | цифры, «бесплатно», главное слово фразы | `kit.js`, шрифты из проекта, одна гарнитура |
| Графики (~30) | линия/столбцы рисуются сами, подсказка у точки, счётчик ₽/%, стрелка роста | цифры продаж, ДРР, выкуп, сравнение периодов | SVG/Canvas из времени; ТОЛЬКО настоящие числа автора или явно условные подписи «пример» |
| Схемы (~30) | процесс по шагам, воронка «заказ → выкуп», маршрут «склад → покупатель», «до / после», весы | объяснение механики, путь денег/товара | узлы въезжают, линии рисуются, активный узел крупнее |
| Интерфейс продукта (самая популярная, ~100) | одна форма превращается в кнопку, переключатель, график, строку поиска, тост, палитру команд — морфинг вместо смены кадров | рассказ о нашем сервисе и его возможностях | свои нейтральные макеты; НЕ рисуй интерфейс Ozon/Wildberries с выдуманными данными (см. «врущие врезки» в MONTAGE.md) |
| Телефон (~20) | телефон в кадре, на экране скриншот автора, палец жмёт | мобильные кабинеты, чат с поддержкой | рамка + настоящий скриншот из refs |
| Фигуры (~40) | круг → карточка → ценник; геометрия подчёркивает мысль, фигура перетекает в другую | абстрактные понятия: рост, риск, выбор | один набор фигур на ролик |
| Частицы (~40) | только если частицы вылетают из объекта и ведут к чему-то (монеты из карточки к кошельку) | деньги, «утечка» | редко, цель обязательна; иначе — запрет (раздел 3) |
| Персонажи (~25) | простые герои: человечки, руки, предметы с «характером» | сторителлинг, шутка, ошибки | стиль рисованной вставки (`photo_hand.js`, `_ui.js`) |
| Фото (~25) | настоящая фото-вставка: медленный наезд, параллакс, вырезка по маске, фото в рамке телефона/карточки | реальные вещи: склад, упаковка, товар | `fx/fetch_assets.py photo`, `fx/effects.py` (sticker / bg image) |
| Музыка (~50) | вставки по ударам/тактам | ролики с музыкой (у нас звука-эффектов нет; ритм берём по словам) | события по `words.json` |
| Код (~20) | блок кода, команда, «терминал» | IT-темы, автоматизация | моноширинный шрифт, строки печатаются |

## 2. Идеи под продавцов маркетплейсов (готовые заготовки, подставляй под смысл фразы)
1. «Копии карточки»: две одинаковые карточки рядом, одна «мигает» красной рамкой, счётчик копий растёт.
2. Лупа наезжает на артикул, под ней всплывает «его копируют».
3. ДРР: дуга-спидометр, стрелка уезжает в красное, число считается.
4. Воронка: показы → клики → заказы → выкупы; ширина воронки сужается по настоящим числам.
5. Склад → покупатель: маршрут коробки по линии, остановки с подписями; «возврат» — коробка едет назад.
6. Ценник «−30 %» накладывается на карточку, число цены переписывается.
7. Рейтинг: звёзды зажигаются по одной, среднее считается.
8. Строка поиска: слово печатается, ниже появляются результаты, нужная карточка поднимается на первое место.
9. Чек-лист: пункты появляются и отмечаются галочкой в такт речи.
10. Весы: слева «выручка», справа «расходы», чаша перевешивает; числа настоящие.
11. Календарь: ячейки дней заполняются (сроки, выкупы по дням).
12. Калькулятор прибыли: строки «цена − комиссия − логистика − себестоимость = прибыль» складываются сверху вниз.
13. Сравнение «до / после»: линия-разделитель ездит по картинке (фото или график).
14. Жалоба/обращение как чат: пузырь за пузырём, последний подсвечен.
15. Таймер/обратный отсчёт для акции: цифры переворачиваются.
16. Колода карточек товара: верхняя уезжает, под ней следующая; выбранная увеличивается на весь экран.
17. Рука подчёркивает слово в тексте на бумаге (doodle-стиль, `photo_hand.js`).
18. Ошибка/«стоп»: знак вырастает из места проблемы, остальное приглушается.
19. Логотипы площадок (Ozon, Wildberries, Telegram): `fetch_assets.py logo`, въезжают по очереди и сравниваются.
20. Человек вырезан по маске, за ним крупное слово (`effects.py text_behind`), в конце слово «выходит» вперёд.

## 3. Как не выглядеть «сделано ИИ» (по разбору промптов с лучшими результатами; в самых популярных работах такие запреты чаще)
- **Свечения и неон без связи с сюжетом** — украшение, не информация. Свечение допустимо только как смысл («контур вокруг человека, пока он говорит о защите»).
- **Взрывы частиц-«конфетти»** — запрещены, если движение не исходит из элемента на экране и не ведёт к чему-то.
- **Затухание между кадрами (crossfade)** — признак непродуманного перехода. Вместо него: один элемент превращается в другой (морфинг) или следующая сцена вырастает из предыдущей.
- **Текст и мелкие «показатели» по углам кадра** — видимость информации без содержания. Текст — в зоне смысла, крупно, и входящий/уходящий текст с разным временем, чтобы не накладывались.
- **Шаблонный вид**: стоковые наборы, одинаковые градиентные плашки, иконки разной толщины линий. Одна гарнитура, один акцентный цвет, одна толщина линии на весь ролик.
- **Пружины**: можно, но с минимальным перелётом (≈2–4 %). Для графика и точки на нём — одна и та же функция, иначе движение фальшиво.
- **Мёртвое время**: застывший кадр дольше ~1,2 с оправдан только пока зритель читает текст.
- **Случайность** без seed (`Math.random`) — запрещена (кадры рендерятся вразнобой; у нас `kit.rng(seed)`).
- Палитра: светлый тёплый фон или почти чёрные поверхности + ОДИН яркий акцент, одинаковый во всех вставках (для Reels: акцент из `preset`/референсов автора).
- Края и циклы: объект, заполняющий кадр, выходит за все четыре угла; в зацикленных вставках первый и последний кадры совпадают.

## 4. Как формулировать идею вставки самому себе (структура удачных промптов)
1. **Одна концепция**: зачем эта вставка (одной фразой).
2. **Запреты**: что здесь точно не делаем (из раздела 3).
3. **Ритм**: на какое слово начинается, сколько длится, что происходит на каждый бит речи (не слово «динамично», а числа).
4. **Метод сборки**: чем рисуем (SVG/HTML/Canvas из времени), какие готовые куски берём (`examples/…`, `_ui.js`).
5. **Самопроверка**: до рендера всех кадров — стоп-кадры (минимум по одному на вставку), проверка читаемости, перекрытия лица и субтитров, пустых отрезков.
Подробные промпты длиннее 100 слов в галерее набирали в разы больше реакций, чем короткие «сделай динамичную анимацию» — детали решают.
